# dotfiles

目的:
- 個人の設定をモジュール単位で管理するためのリポジトリ。

サブディレクトリ:
- [mise/](./mise/) — Kaggle 向けのタスクとテンプレートを含むモジュール
  - [mise/scripts/](./mise/scripts/) — タスク実装用スクリプト
    - [mise/scripts/lib/](./mise/scripts/lib/) — 共通関数・初期化処理
    - [mise/scripts/templates/](./mise/scripts/templates/) — 生成プロジェクト用テンプレート
  - [mise/tasks-windows/](./mise/tasks-windows/) — Windows 向けエントリポイント

備考:
- コマンドの詳細は各サブディレクトリ内のドキュメントを参照してください。
